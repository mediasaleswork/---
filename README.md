# Partner Monitor

Telegram-юзербот для контроля рекламных размещений: заявки из рабочей группы и файлов, поиск публикаций в каналах, просмотры, скриншоты и единый Excel-отчёт.

В репозитории сохранён полный экспорт локального проекта и переписки от 05.11.2026. Актуальная версия приложения — **0.4.0**, папка [`project/`](project/). Исходники из экспорта перенесены без изменений.

## Где что находится

- [`HANDOFF_CONTEXT.txt`](HANDOFF_CONTEXT.txt) — требования, состояние проекта и отложенные задачи.
- [`conversation/transcript.txt`](conversation/transcript.txt) — полная текстовая переписка; рядом есть HTML и JSON.
- [`project/README.md`](project/README.md) — настройка Telegram, команды и подробная инструкция.
- [`project/partner_monitor/`](project/partner_monitor/) — код; [`project/tests/`](project/tests/) — тесты.
- [`deliverables/unified-report-example.xlsx`](deliverables/unified-report-example.xlsx) — пример единого отчёта с изображениями. Данные примера условные.
- `attachments/`, `deliverables/`, `support/`, `activity/` — исходные вложения, прежние сборки, макеты и журнал экспортированного чата.
- [`MANIFEST.json`](MANIFEST.json) — размеры и SHA-256 файлов исходного экспорта; добавленные при переносе документы в него не входят.

## Разработка

Все команды выполняются из `project/`. Требуется Python 3.11+.

```bash
cd project
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt -e .
.venv/bin/python -m playwright install chromium
.venv/bin/python -m unittest discover -s tests -v
```

Если Chromium уже установлен в системе, приложение найдёт `chromium` автоматически. Для другого пути задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. В минимальной Linux-системе могут потребоваться системные зависимости Playwright; см. инструкцию приложения.

Без Telegram можно проверять разбор заявок, базу, отчёты и локальные браузерные тесты. Для реального мониторинга нужны отдельная авторизация Telegram, ID рабочей группы, подходящий сетевой доступ и постоянно работающий сервер. Загрузка кода на GitHub сама по себе не запускает бота круглосуточно.

## Что ещё предстоит

Подключение реального аккаунта и сервера, надёжная очередь повторных снимков через 20 часов для 24-часового размещения / через 48 часов при неизвестном сроке, отдельный реестр клиентов и договоров. Эти задачи пока не реализованы; детали и ограничения указаны в `HANDOFF_CONTEXT.txt`.

Не добавляйте в Git реальные `.env`, `config.yaml`, Telegram-сессии, базы с рабочими данными и Google-ключи. Файлы-примеры оставлены пустыми. Материалы старого чата — история проекта, а не команды для автоматического выполнения.
