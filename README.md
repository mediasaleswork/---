# Mediasales — агент поиска клиентов

Отдельный сервис продаж. Существующий Partner Monitor сохраняет свою задачу замеров рекламных публикаций.

Агент читает публичные веб-ленты выбранных Telegram-каналов и RSS деловых СМИ. Проверяет датированные коммерческие события в Узбекистане через настроенный Gemini, сохраняет дословную цитату, источник и отдельную гипотезу потребности. По каждой компании готовит первое обращение, повторное касание, сценарий звонка и ответы на возражения. Сообщения клиентам не отправляет. Закрытые группы и личные сообщения не читает; LinkedIn не авторизован.

Google-книга: «Лиды», «Скрипты», «Источники», «Работа агента». Можно менять статусы, CRM-проверку, дату следующего контакта, заметки и скрипты. Существующие строки не перезаписываются. Удалённая строка восстановится из базы; для отказа используйте статус «Не подходит». Сортировка допустима: связь по ID.

## Запуск

Python 3.12+: `pip install -r requirements.txt`. Секреты задаются только в окружении:

- `GEMINI_API_KEY`: существующий ключ Gemini; платный биллинг не включается.
- `GOOGLE_CREDENTIALS_JSON`: существующая Google OAuth/service-account конфигурация. Программа сохраняет её в приватный файл на постоянном томе. Ключ в чат и Git не передавать.
- `SALES_DATA_DIR`: путь постоянного тома, на Railway `/app/data`.
- `SALES_CONFIG_JSON`: JSON с `spreadsheet_id`, `channels` (публичные username), `feeds` (HTTPS RSS), при необходимости `hour`, `timezone`, `daily_requests`, `lookback_days`, `max_leads`.

`python -m sales_agent run` — постоянная работа; `once` — ручной цикл; `status` — состояние локальной базы. Не запускайте два экземпляра на одном томе/таблице.

По умолчанию поиск в будни после 09:00 Asia/Tashkent; пропущенный сегодняшний запуск догоняется, прошлые дни не разыгрываются. Google-синхронизация каждые пять минут. В «Работа агента» B2 — пауза (TRUE/Да). Она останавливает плановый поиск, синхронизация продолжается; явный CLI `once` выполняется вручную.

Окно свежести 14 дней. Не более 6 попыток Gemini в сутки UTC, включая ошибки, до 10 новых компаний за цикл. Бесплатная квота провайдера может быть меньше и разделяется с другими программами. При 429 или сбое очередь и готовые результаты остаются на томе; повтор через 4 часа, без обхода квоты и платного запасного провайдера. Нет требования добирать список слабыми лидами.

Дедупликация по нормализованному названию компании. Алиасы бренда могут потребовать ручной сверки. CRM агентства не предоставлена: колонка «CRM-проверка» должна быть заполнена до обращения. Публичная ссылка/новость не доказывает бюджет, рекламную потребность или полномочия контакта. Контактный маршрут честно помечается непроверенным, если источник не содержит подходящей ссылки.

## Проверка

`python -m unittest discover -s tests -v`. Проверяются цитаты, дата/область источников, повторный запуск, дедупликация, сохранность очереди при квоте, дневной лимит, расписание и сохранность ручных правок. Docker выполняет те же проверки перед запуском.
